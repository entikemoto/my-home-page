### この回の要点（先に読む）

- **変わったこと**: v2.1.180〜v2.1.190（11バージョン）を確認。**`/config key=value`** でセッション中に設定変更が可能（v2.1.181）。**`CLAUDE_CLIENT_PRESENCE_FILE`** で在席中のスマホ通知を抑制できる（v2.1.181）。**Auto mode の destructive git コマンド自動ブロック**（v2.1.183）。**`claude mcp login/logout`** でCLI認証が可能に（v2.1.186）。
- **このVaultへの影響**: Push notification 有効化（繰越タスク）と合わせて `CLAUDE_CLIENT_PRESENCE_FILE` を設定できる。モデル更新なし。

- 実行時バージョン: **v2.1.190**（v2.1.179 から自動更新済み）
- 調査範囲: v2.1.180〜v2.1.190（GitHub Releases 直接取得）
- モデル更新: なし → `/methods-audit` 前倒しトリガー非該当

#### 発見した新機能と対応

- **`/config key=value`**（v2.1.181）: 検討 — セッション中に設定を即変更可能（例: `/config thinking=false`）。`/config --help` で全キーをリスト表示
- **`CLAUDE_CLIENT_PRESENCE_FILE`**（v2.1.181）: 即適用候補 — マーカーファイルを指定すると在席中はスマホ push 通知を抑制。繰越タスク「Push notification 有効化」と合わせて設定
- **Auto mode: destructive git コマンドのブロック**（v2.1.183）: 確認のみ — `git reset --hard`・`git stash drop`・`terraform destroy` 等を自動ブロック。当 Vault は auto mode 未使用のため影響なし
- **`attribution.sessionUrl` 設定**（v2.1.183）: 不要 — commit/PR のセッションリンクを省略する設定。個人用途では不要
- **Stream-stall hint 改善**（v2.1.185）: 自動適用 — 10秒→20秒に延長、メッセージ文言も改善
- **`claude mcp login/logout <name>`**（v2.1.186）: 検討 — CLI から MCP 認証（対話メニュー不要）。GitHub MCP 再認証時に使える
- **`/workflows` ステータスフィルター**（v2.1.186）: 自動適用 — `f` キーでフィルター。Dynamic Workflows 試用時に便利
- **`/plugin` の Skills セクション**（v2.1.186）: 自動適用 — Installed タブに Skills 一覧が表示
- **`sandbox.credentials` 設定**（v2.1.187）: 検討 — sandbox からの credential ファイル・秘密環境変数アクセスをブロック。PHI プロジェクトへの適用候補
- **org-configured model restrictions**（v2.1.187）: 不要 — チーム管理機能。個人利用のため対象外
- **v2.1.190: バグ修正・信頼性改善のみ**: 自動適用済み。手動対応事項なし
