### この回の要点（先に読む）

- **変わったこと**: 中島聡さん（元 Microsoft・「Life is Beautiful」著者）の週刊メルマガと X 投稿を毎週自動収集し、開発環境の改善に活かすスキル「中島 Scout」を導入した
- **いままでとの違い**: メルマガは読んで終わりになることが多かったが、今後は毎週火曜日に AI が自動で読み込み、開発環境への応用可能な知見を抽出・提案する
- **メリット**: 日本語圏で最も参照されるソフトウェアエンジニアの一人の知見を、読み逃しなく開発環境に取り込み続けられる

### 中島聡さんとは

元 Microsoft のソフトウェアエンジニア。Windows の右クリックメニューなど現代 UI の基礎を作った人物として知られています。現在は「Life is Beautiful」というメルマガ・ブログで、AI・プロダクト設計・スタートアップ経営について週次で発信しています。

日本語で AI 開発・プロダクト思想を語る発信者の中で、具体性と実践性の両方を備えた数少ない存在です。

### Karpathy Scout と何が違うか

今回導入した中島 Scout は、先週導入した Karpathy Scout と同じ仕組みで動きます。大きな違いは収集元です。

- Karpathy Scout → X（英語、主に短い発言）を WebSearch で収集
- 中島 Scout → **Gmail でメルマガを直接受信**（日本語、毎週火曜日着）＋ X 投稿で補完

メルマガは Gmail の受信ボックスから AI が直接読み込む設計です。週刊メルマガが届いた午後（13:00）に自動実行し、その週の内容をすぐ分析します。

### 4つの分析軸

中島さんの発信スタイルに合わせた4軸で内容を分類します。

- ツール・ワークフロー — 開発環境や作業効率の話
- プロンプト・AI活用法 — Claude や GPT との協働の仕方
- 設計・プロダクト哲学 — ソフトウェア設計思想、プロダクトの判断軸
- スタートアップ・意思決定 — 事業判断・優先順位づけの考え方

この4軸に該当する内容だけを抽出し、現在の Vault の状態と照らし合わせて「未導入のもの」だけを提案します。

### 週のインプットサイクルが完成した

今回の導入で、週の頭に2本のインプットが入る構成になりました。

```
月曜 10:30 → Karpathy Scout 自動実行（英語・X 発言）
火曜 13:00 → 中島 Scout 自動実行（日本語・メルマガ）
```

どちらも「収集・分析して提案まで」が自動で、採否の判断はユーザーが行います。

### 今回対応したこと

- ✅ `/nakajima-scout` スキルを新規作成（`~/.claude/skills/nakajima-scout/`）
- ✅ Gmail MCP 連携（`mailmag@mag2premium.com` を自動取得）
- ✅ `launchd` で週次自動実行を設定（毎週火曜 13:00）
